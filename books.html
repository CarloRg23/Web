Books Sales and
Ratings Analysis with SQL

This section will walk you through the process of
completing the project, as well as the tools that I used.

What is the project about?

In this project I use SQL to analyze book sales performance data, ratings and classifications in order to give key recommendations to an aspiring author who wants to publish a new book and have a higher chance of success.

Key components of the project

JOINS, CTEs, Window Functions, Aggregate Functions, Subqueries, String Functions, DDL, DML, Data Cleaning, Data Analysis, Insights, Recommendations.

The dataset

For this project I worked on a dataset that contains key information about books sales and their ratings. Other columns include various aspects such as publishing year, author details, and genre classification.



Project Walkthrough

This project is mainly divided into 4 parts:

  1. Importing and loading the data
  2. Data cleaning and standardization
  3. Data analysis and exploration through queries
  4. Final insights and recommendations for the client

3. ANALYSIS AND EXPLORATION THROUGH QUERIES

Now that we have cleaned and standardized our data, we can work with it.

There are many key insights that can be obtained from this dataset and that will allow us to give recommendations to our client or stakeholders.

To achieve this, I wrote multiple queries with the use of several functions and statements. Here is a summary of what I did:

  • Most popular genre

    • Getting the total number of books for each genre, using aggregate function COUNT.

  • Minimum, maximum and average rating

    • Used MAX, MIN and AVG to analyze book ratings.

  • Ratings according to book prices

    • Joined both tables and used a case statement to understand if book prices have an influence on book ratings.

  • Ratings according to genre

    • Grouping by genre to see which genre has the best ratings.

  • Average units sold by genre

    • Joined both tables and grouped by genre to see which books sell the best according to genre.

  • Top 5 best-selling books across all genres

    • Here I decided to make a more complex query in order to combine IF statements, window functions and string functions.

  • Top rated books for each genre

    • Used the RANK window function to get the top-rated book for each genre.

    The author may try to emulate any of these books if they want their book to achieve critical success.

  • Units sold by publisher

    • Some publishers sell more books than others. This may influence book selling success for the aspiring author.
